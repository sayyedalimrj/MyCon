## Prepaid-GPU acceptance decision

**Release status: OFFLINE COMPATIBILITY REVIEW PASSED, LIVE-NVIDIA-RUNTIME UNVERIFIED.**

Avoid claiming guaranteed absence of technical errors: no offline CI can reproduce dynamic Colab drivers, package mirrors, network failures, VMs, CUDA compiler or actual video geometry. Before authorizing an expensive GPU training run, require separately captured evidence of (a) full source ZIP + model/derived receipts, (b) 8-bin temporal and sparse coverage acceptance, (c) exact runtime package and torch/torchvision/NumPy/PyTorch3D versions, (d) real CUDA kernels including MASt3R/GS rasterizer/fused-SSIM/torch_scatter/knn, (e) bounded **real input** optimizer smoke, and (f) actual resumed optimizer state under a forced/controlled interruption. A pass in the NVIDIA branch does not automatically validate the separate gsplat branch.

**Preservation:** No user Recorder/pose.csv/IMU, previous model checkpoint, Colab runtime or expensive training was modified or launched during this code review. Keep PR #31 unmerged until real GPU + geometry/BIM acceptance.
