## Comparison decision and limitations

- **A: held-out NVS**: 6999 vs new and 192 frames vs expanded only on identical independently reserved view IDs, reference RGB image hashes, camera frame/intrinsics and color/masks. Report PSNR/SSIM per view, LPIPS `not_evaluated` until exact pinned evaluator runs; time/VRAM only with verified instrumentation. Prevent using any held-out image to optimize the new model.
- **B: surveyed geometry**: raw GS/COLMAP vs cleaned/surface-aware Geometry A/2DGS; signed as-built survey and held-out registration controls required. Accuracy, completeness, F1@τ, Chamfer, finite-plane/corner error, original point/edge survival, density/occlusion stress; non-metric data remains `not_evaluated` for meter-based metrics. No GT from predicted geometry, no fitting on test anchors.
- **C: progress**: independent accepted quantity and BOQ activity weights, dated baseline, IFC GlobalId and adjudicated observability; no execution-rate numerical claim from NVS/coverage alone.

## Statistical/reproducibility boundaries

Freeze site/building/capture-session splits and exact held-out view roster before running; no matching on view name alone if reference hashes differ. Within each site average the per-view paired deltas first; use site-cluster bootstrap for independent sites (fewer than two => `not_evaluated`; with very few sites label exploratory, not definitive). Preregister τ (e.g., 1/2/5/10 cm) against survey uncertainty, report sample denominators and failures; state PSNR identical-image `+inf` without silent imputation. Review figure sources, metric provenance, code commit SHA and licensing before approving any thesis claim.
